## What it does

`main.py` (Python standard library only) writes a single ~100-word monologue
to `/output/entry.txt`, spoken by a fantasy villain who is secretly just very
tired. The tiredness lives in the rhythm, the pauses and the small deflections
— never in a plain statement of weariness. The speaker is a specific villain
with a history (a thorn hedge planted in forty-three, a crown that whispers
tax figures) and a scheme, and the last line lands the sting.

## Run it

```sh
python3 main.py
```

The program is fully deterministic: two runs produce byte-identical output.
